# 시작월·종료월 선택

사용자가 고정지출의 시작월을 고르기 어렵다고 지적한 부분을 월 선택기 하나로 한정해 변경했습니다. 등록·수정 대화상자와 통합 수정표의 시작월·종료월이 대상입니다. 금융 데이터, YYYY-MM 저장 형식, 기존 보라색 테마·색상 변수·글자 크기·나머지 화면은 유지합니다. 카드 청구 월과 날짜 단위 달력은 이번 변경 대상이 아닙니다.

## 참고 화면과 변경

- [Copilot Money](https://mobbin.com/screens/b9d33ef6-9afe-4af0-ba0f-5b570bf7aa1c?utm_source=chatgpt&utm_medium=ai-assistant&utm_source_platform=mcp): 연도 아래에 12개월을 배치하고 선택된 월을 강조하는 팝오버가 보입니다. 이 구조와 이전·다음 연도 이동을 주된 참고로 삼았습니다.
- [Melio](https://mobbin.com/screens/62fdc697-0638-4f73-8c11-f047979a3100?utm_source=chatgpt&utm_medium=ai-assistant&utm_source_platform=mcp): 12개월을 격자로 표시하고 선택된 달을 채운 화면이 보입니다. 월 전체를 한 번에 보여주는 구성의 보조 참고입니다. 여러 연도를 세로로 나열하는 배치는 가져오지 않았습니다.

기존 브라우저 month 입력을 같은 필드 자리의 버튼으로 바꾸고, 클릭하면 연도·12개월 격자·닫기·선택 가능한 경우 종료월 없음이 열립니다. 연도 직접 입력, 한국어 표기, 선택 즉시 입력값 적용과 키보드 동작은 이 제품에 맞춰 정한 세부 구현입니다. 종료월을 비울 수 있는 기존 의미와 YYYY-MM 값은 그대로 유지합니다. 사용자가 월을 고르기 전에는 값이 바뀌지 않습니다.

## 동작과 범위

연도는 1900~2199 범위를 직접 입력하거나 한 해씩 이동합니다. 종료월은 현재 입력된 시작월보다 이른 달을 선택할 수 없습니다. 월 선택은 임시 입력만 바꾸고, 기존 저장 버튼에서만 서버에 저장합니다. 시작월·종료월 외의 입력과 본문 달력에는 적용하지 않습니다.

월 선택창은 하나만 필요할 때 생성하고 닫으면 제거합니다. 지원 브라우저에서는 popover의 최상위 레이어를 사용해 수정표나 대화상자의 스크롤 경계에 잘리지 않도록 배치하며, 화면 가장자리를 넘지 않게 위치를 조정합니다. 미지원 환경에서는 필드 아래에 같은 월 선택기를 표시합니다. 별도 라이브러리를 추가하지 않습니다.

방향키·Home/End·PageUp/PageDown으로 월과 연도를 이동하고, Esc나 바깥 클릭으로 변경 없이 닫습니다. 연도 입력에서 Enter는 월 선택으로 포커스를 옮기고 폼을 제출하지 않습니다. 월 선택·닫기 후 원래 버튼으로 포커스를 돌립니다. 선택한 월·현재 월·선택 불가 월을 구분합니다.

계산과 저장 형식은 변경하지 않으며 새 데이터나 DB 마이그레이션이 없습니다. 컴포넌트 검사와 앱 DOM 검사에서 연도 이동, 월 선택 이벤트, 종료월 범위·지우기, 취소·키보드·비활성 상태·이스케이프, 화면 가장자리 배치, 등록·통합 수정 저장을 검증합니다. 연도 입력에는 금액용 천 단위 쉼표 처리를 적용하지 않습니다.

관리형 미리보기에서 포트 릴레이 연결 시간이 초과되어 실제 브라우저 캡처와 변경 전후 이미지는 만들지 못했습니다. 화면 배치는 DOM·스타일 검토와 위치 계산 검사까지 확인했습니다.
