# 차트에 적용한 9가지 모션

[참고한 Instagram 릴스](https://www.instagram.com/reel/Dfnmg3_yxMI/)를 브라우저로 직접 열어 영상의 데모와 설명에 나온 아홉 가지를 확인했습니다. 영상 속 용어를 기준으로 모아의 실제 금융 데이터와 조작에 연결했습니다. 원본의 프레임별 시간이나 곡선을 복제한 것은 아닙니다.

| 영상의 기능 | 모아에서 쓰는 곳 | 표시·조작 기준 |
| --- | --- | --- |
| Bar grow | 통합 통계 → 형태 → 막대 그래프, 대출별 부담 비교 | 실제 금액에 비례해 막대가 자랍니다. 차액의 음수는 0선 아래로 표시합니다. |
| Line draw | 홈 순자산 흐름과 기존 선 그래프 | 선이 왼쪽부터 드러납니다. 실제 기록과 미래 예상의 실선·점선 구분을 유지합니다. |
| Donut fill | 홈 → 보유 자산 구성 | 예금·현금, 주식·투자, 퇴직금·연금의 현재 평가액 비중을 원형으로 채웁니다. 부채를 자산 구성에 섞지 않습니다. |
| Stacked bar | 통합 통계 → 월별 지출 구성 | 대출 원금·이자, 카드, 정기 지출, 기타 지출이 순서대로 쌓입니다. 현재 통계의 기간·필터를 그대로 따릅니다. |
| Progress ring | 홈 → 이번 달 예산 | 등록한 지출 계획 ÷ 예산입니다. 실거래 사용액으로 단정하지 않습니다. 한도가 없으면 ‘미설정’, 초과 시 실제 비율과 초과 상태를 표시합니다. |
| Sparkline | 홈 → 자산 구성의 각 금액 아래 | 해당 자산 종류의 저장된 날짜별 잔액과 현재 잔액, 최근 최대 8개 지점을 표시합니다. 서로 다른 날짜가 2개 미만이면 생략합니다. |
| Tooltip | 도넛, 예산 링, 통계 막대·누적 막대, 대출 비교 | 마우스, 초점, 터치로 항목과 정확한 원화 값을 표시합니다. 기존 선 그래프 툴팁도 유지합니다. |
| Highlight pulse | 홈 요약 금액, 대출 월 이자 합계 | 저장된 금융 데이터의 버전과 표시 금액이 함께 바뀐 경우 짧게 강조합니다. 최초 방문이나 단순 화면 이동에는 강조하지 않습니다. |
| Sort animation | 대출 현황 → 대출별 부담 비교 | 월 이자/잔액과 큰/작은 금액순을 선택하면 막대 행이 실제 순위 위치로 이동합니다. 금융 내역의 원본 순서를 저장하거나 변경하지 않습니다. |

## 데이터와 표시 기준

- 월별 누적 막대 합계는 같은 조회 조건의 기존 통계 지출·상환 합계와 일치합니다. 카드대금에 포함된 정기 지출과 회사 퇴직연금 납입액을 중복 합산하지 않습니다.
- 모든 숫자는 처음부터 최종 계산값을 표시합니다. 금액을 가짜로 카운트하거나 기록 없는 기간의 추이를 만들어내지 않습니다. 스파크라인은 계좌별 추이가 아니라 자산 종류별 저장 기록입니다.
- 화면에 들어온 차트만 짧게 재생하며, 같은 데이터 상태는 현재 방문 중 반복 재생하지 않습니다. 정렬은 사용자 조작에 반응합니다.
- 운영체제의 동작 줄이기 설정을 따르고 금액 숨김 상태에서는 새 진입·정렬·강조 모션을 생략합니다. 툴팁에도 숨긴 금액을 사용합니다. 키보드의 좌우/처음/끝 이동과 Escape 닫기를 지원합니다.
- 기존 색상 토큰과 글자 크기 체계를 사용합니다. 데이터 저장 형식·잔액·상환 계산·현재의 작은 달력 높이는 바꾸지 않습니다. 외부 애니메이션 서비스나 추적 스크립트를 추가하지 않습니다.

## 검증

모션·비율·0원/초과·음수 차액·중복 합산 방지·실제 저장 기록·금액 숨김·키보드 툴팁·정렬 위치와 원본 보존을 테스트합니다. 전체 테스트 144개와 Worker 빌드/문법 검사, 20개 경로를 포함한 DOM/API 기능 검사를 통과했습니다.

관리형 로컬 브라우저 미리보기는 포트 중계 오류가 났으며, 배포된 소유자 전용 미리보기의 브라우저는 로그인 화면으로 막혔습니다. 실제 브라우저 화면 배치와 애니메이션 프레임의 시각 검증은 완료하지 못했습니다. 접근 범위는 넓히지 않았습니다.
