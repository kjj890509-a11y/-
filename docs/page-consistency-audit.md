# 전체 페이지 통일성 점검

20개 메뉴를 데이터가 있는 상태, 빈 상태, 금액 숨김 상태로 각각 확인합니다. 페이지 전환과 표시 점검은 서버 데이터를 저장하지 않습니다.

## 공통 기준

모든 화면은 제목·동작 버튼, 그룹 탭, 본문 순서의 한 프레임을 사용합니다. 맞춤 대시보드의 제목처럼 별도 래퍼에 들어 있던 요소도 같은 위치에 배치합니다. 제목은 기존 내비게이션 명칭과 일치시키고, 브라우저 탭 제목도 현재 메뉴를 표시합니다. 원래 버튼 노드와 이벤트 속성은 보존합니다.

요약 영역은 홈·자금 계획·자산·맞춤 대시보드·대출·달력에서 같은 카드 여백·테두리·숫자 크기·라벨 크기를 사용합니다. 지표 수에 맞춰 3개 또는 4개를 표시하고 좁은 화면에서는 2열, 가장 작은 화면에서는 1열로 배치합니다. 금융 의미가 다른 지표를 새로 만들거나 숨기지 않습니다. 대시보드 안의 표·그래프·달력과 저장된 카드 크기·순서는 유지합니다.

공통 페이지 프레임은 기존 도움말·필터·AI 단계 구성을 만든 다음 적용합니다. 이 순서로 AI 단계와 통계 필터를 유지하며, 홈의 부분 전환 후에도 프레임과 기존 버튼을 교체하지 않고 새 요약 영역에만 같은 규칙을 적용합니다.

## 점검 메뉴

| 그룹 | 메뉴 |
|---|---|
| 홈 | 자산 한눈에, 통합 입력·수정, 맞춤 대시보드 |
| 보유 자산 | 전체 자산, 예금·현금, 주식·투자, 퇴직금·연금 |
| 수입·지출 | 전체 내역, 수입·지출 내역, 정기 지출, 예정 거래, 입출금 달력 |
| 대출·카드 | 대출 현황, 카드 청구, AI 상담 |
| 자금 계획 | 월별 전망, 급여일 전망, 월 예산 |
| 분석·기록 | 기간별 분석, 자산 기록 |

## 문구 정리

- 자산 페이지의 제목을 메뉴와 같은 ‘전체 자산’으로 통일합니다.
- 카드 페이지와 월별 입력 패널에 반복되던 등록 안내를 줄이고, 전체 청구 목록의 설명을 간단히 합니다. 보기 삭제는 청구를 삭제하지 않는 기존 동작과 안내 메시지를 유지합니다.
- 반복되는 드래그 사용법과 ‘등록순은 추가 순서를 기준으로 한다’는 내부 설명을 기본 화면에서 제거합니다. 변경됨·저장됨·연결 실패 안내와 방향키 대안은 유지합니다.
- 통합 입력의 제목 설명과 저장 안내를 짧게 합니다. 수정값이 다른 페이지에서도 유지된다는 안내는 보존합니다.
- 맞춤 대시보드의 반복 머리말과 각 카드에 이미 있는 집계 기준 설명의 중복 각주를 제거합니다.
- 통계의 중복 설명은 줄이고, 기록·일정·예상 구분과 자세한 계산 기준은 유지합니다.
- 전망 배너의 긴 가정 설명은 기존 계산 기준 도움말에서 확인하도록 옮깁니다. 가정 내용을 삭제하지 않습니다. 요약 지표를 배너보다 먼저 표시합니다.

색상 선택기를 추가하지 않고 보라색 디자인 변수를 유지합니다. 금융 데이터·계산·저장 형식·API 키·사이트 공개 범위·DB는 변경하지 않습니다.

## 검증 범위

앱 DOM 검사에서 20개 메뉴 × 3개 상태의 제목·탭·본문 순서, 하나의 제목, 내비게이션 명칭 일치, 공통 요약 클래스와 불필요 문구 제거를 확인합니다. 도움말과 제목 동작 버튼, AI 단계, 홈 부분 전환을 별도로 확인하고 표시 과정에서 서버 쓰기가 없음을 검사합니다. 기존 금융 계산·저장·드래그·입력·키보드·개인정보 숨김 검사를 함께 실행합니다.

관리형 미리보기의 포트 릴레이 연결이 시간 초과되어 실제 브라우저의 픽셀 배치와 스크린샷은 확인하지 못했습니다.
